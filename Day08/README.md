# Day 8 - For Loop (`Day08/forLoop.js`)

Topics covered:

- `for` loop syntax (`for` initialization; condition; increment)
- Printing ranges of numbers
- Even numbers using `%` operator and by incrementing the loop by 2
- Multiplication tables with string concatenation
- Factorial calculation with a loop
- Sum of a number range
- Divisibility checks
- Nested `for` loops to print patterns
- Reversing a number using `toString()`, a loop, and `Number()`

Problems included:

1. Print numbers from 1 to 100 using a for loop.
2. Print all even numbers between 1 and 100 using the modulus (`%`) operator.
3. Print all even numbers between 1 and 100 by incrementing the loop by 2.
4. Print the multiplication table of 7.
5. Find the factorial of a number (e.g., 5! = 5*4*3*2*1 = 120).
6. Print the sum of numbers from 1 to 100.
7. Print all numbers divisible by 3 between 1 and 50.
8. Print a `*` pattern (1 to 5 stars) using nested for loops.
9. Reverse a number using a for loop (e.g., 1234 becomes 4321).

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node Day08/forLoop.js
```
