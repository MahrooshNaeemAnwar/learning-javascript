# Day 6 - Arrays (`Day06/arrays.js`)

Topics covered:

- Creating arrays with `const`
- Accessing elements using index (`fruits[0]`)
- `length` property to get the array size
- `push()` / `pop()` to add/remove at the end
- `unshift()` / `shift()` to add/remove at the beginning
- Looping through an array with `for` and `for...of`
- `indexOf()` to find the index of an element
- `splice()` to remove an element from a specific position
- Summing all elements of a number array with a loop

Problems included:

1. Create an array of 5 fruits and print the first and last element.
2. Find the length of an array.
3. Add an element to the end of an array using `push()`. Then remove the last element using `pop()`.
4. Add an element to the beginning using `unshift()`. Remove the first using `shift()`.
5. Loop through an array and print each element.
6. Find the index of a specific element in an array using `indexOf()`.
7. Remove an element from a specific position using `splice()`.
8. Create an array of numbers and find the sum of all elements using a loop.

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node Day06/arrays.js
```
