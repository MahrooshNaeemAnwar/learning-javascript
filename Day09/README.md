# Day 9 - While & Do-While Loops (`Day09/whileLoops.js`)

Topics covered:

- `while` loop syntax (`while` condition)
- Reverse counting with `while`
- Summing a range with `while`
- Multiplication tables with `while`
- `do...while` loop (runs at least once)
- Even numbers with `while`
- Divisibility checks with `while`
- Factorial with `while`
- Fibonacci series with `while`

Problems included:

1. Print numbers from 1 to 10 using a while loop.
2. Print numbers from 10 to 1 (reverse) using a while loop.
3. Calculate the sum of numbers from 1 to 100 using a while loop.
4. Print the multiplication table of 5 using a while loop.
5. Use a do-while loop to print numbers from 1 to 5.
6. Print all even numbers between 1 and 20 using a while loop.
7. Print all numbers from 1 to 50 that are divisible by 5 using a while loop.
8. Find the factorial of a number using a while loop.
9. Print the Fibonacci series up to 10 terms using a while loop.

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node Day09/whileLoops.js
```
