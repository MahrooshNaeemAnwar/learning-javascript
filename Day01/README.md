# Day 1 - Variables & Data Types

File: `variables.js`

Topics covered:

- Declaring variables with `let` and constants with `const`
- String, number, boolean, `undefined`, and `null` data types
- `typeof` operator (including the classic `typeof null === "object"` quirk)
- Swapping two variables without a third variable (using destructuring)
- Hoisting with `var`

Problems included:

1. Declare a variable using `let` and assign your name to it. Print it.
2. Declare a constant using `const` and assign your age. Print it.
3. Create three variables: one string, one number, and one boolean. Print all three.
4. Declare a variable without assigning a value. Print it.
5. Create a variable with `null` value. Print it.
6. Swap the values of two variables without using a third variable.
7. What is the `typeof` each of these: `"Hello"`, `42`, `true`, `undefined`, `null`.
8. Create a variable using `var` (old way) and print it. Then access it before declaration (hoisting).

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node variables.js
```
