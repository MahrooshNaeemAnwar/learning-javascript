# Day 7 - Objects (`Day07/objects.js`)

Topics covered:

- Creating objects with `const`
- Accessing properties using dot notation (`user.name`) and bracket notation (`user["age"]`)
- Adding a new property to an existing object
- Updating an existing property value
- Deleting a property using the `delete` keyword
- Looping through an object with `for...in`
- Methods (functions inside objects) using `this`
- Array of objects

Problems included:

1. Create an object representing a person with name, age, and city. Print all properties.
2. Access object properties using both dot notation and bracket notation.
3. Add a new property to an existing object (e.g., add "email" to the person object).
4. Update an existing property value.
5. Delete a property from an object using the `delete` keyword.
6. Loop through an object using `for...in` loop and print all keys and values.
7. Create an object with a method (a function inside an object) that prints "Hello".
8. Create an array of objects (e.g., array of students with name and grade). Loop and print each.

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node Day07/objects.js
```
