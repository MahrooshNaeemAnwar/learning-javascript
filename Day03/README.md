# Day 3 - Strings & Template Literals

File: `strings.js`

Topics covered:

- String concatenation with the `+` operator
- Template literals (backticks)
- `length` property
- `toUpperCase()`
- `slice()`
- `replace()`
- `split()`
- `includes()`

Problems included:

1. Concatenate two strings using the `+` operator.
2. Use template literals (backticks) to create a sentence: `"My name is [name] and I am [age] years old."`
3. Find the length of the string `"JavaScript"`.
4. Convert the string `"hello world"` to uppercase.
5. Extract the word `"World"` from the string `"Hello World"` using `slice()`.
6. Replace `"bad"` with `"good"` in the string `"This is a bad day"`.
7. Split the string `"apple,banana,grape"` into an array using `split()`.
8. Check if the string `"JavaScript"` contains the word `"Script"` using `includes()`.

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node Day03/strings.js
```
