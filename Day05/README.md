# Day 5 - Switch & Ternary Operator (`Day05/switch_ternary.js`)

Topics covered:

- `switch` statement for multiple conditions (day names, seasons)
- `switch` with a calculator using `+`, `-`, `*`, `/`
- `default` case for invalid values
- Handling division by zero in `switch`
- Ternary operator `? :` for short if-else
- Nested ternary to check positive, negative, or zero

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node Day05/switch_ternary.js
```
