# Day 4 - Conditionals (if/else)

File: `conditionals.js`

Topics covered:

- `if` / `else if` / `else` statements
- Comparison operators (`>=`, `<`, `===`, `!==`)
- Logical operators (`&&`, `||`)
- Modulo operator (`%`)

Problems included:

1. Check if a number is positive, negative, or zero.
2. Check if a person is eligible to vote (`age >= 18`). Print "Eligible" or "Not Eligible".
3. Find the largest of three numbers using if/else.
4. Given a percentage, print the grade: A (`>=90`), B (`>=75`), C (`>=50`), F (`<50`).
5. Check if a year is a leap year (divisible by 4 but not by 100, OR divisible by 400).
6. Check if a number is divisible by both 3 and 5.
7. Given the time (0-24), print "Good Morning" (`<12`), "Good Afternoon" (`12-17`), "Good Evening" (`>=17`).

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node Day04/conditionals.js
```
