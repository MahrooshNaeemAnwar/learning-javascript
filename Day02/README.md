# Day 2 - Operators

File: `operators.js`

Topics covered:

- Arithmetic operators (`+`, `-`, `*`, `/`, `%`)
- Comparison operators (`>`, `==`, `===`)
- Logical operators (`&&`, `||`)
- Increment operators (pre-increment `++i` vs post-increment `i++`)
- Assignment operators (`+=`)

Problems included:

1. Add two numbers and print the result.
2. Subtract, multiply, and divide two numbers. Print all results.
3. Find the remainder when 15 is divided by 4 using the modulus operator.
4. Check if a number is even or odd using modulus.
5. Use comparison operators to check if 10 is greater than 5, and if 3 is equal to `"3"` (both `==` and `===`).
6. Use logical operators (`&&`, `||`, `!`) — e.g. `age >= 18 && hasLicense`.
7. Increment a variable using both pre-increment and post-increment. Print the difference.
8. Use the assignment operator `+=` to add 5 to a variable.

## How to Run

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
node Day02/operators.js
```
